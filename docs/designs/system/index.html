Foundation

One idea carries the brand

The mark is a wallet with a coin in it. That coin — amber-400 — is the only warm colour in the system, and it means one thing everywhere: this money involves someone else.

Shared money. Fills and marks only — never text.

The amber rule. Amber marks that an amount belongs to more than one person: the share rule, the owed nudge, space avatars, shared budget bars, the add button. It never carries direction — whether you are owed or owing is always a separate colour and an explicit label.

Amber is never text. #FBBF24 measures 1.67:1 on white. Where amber-coloured words are needed, the system uses shared.strong (amber-700) at 4.84:1.

Signature

The share rule

A hairline beneath a shared amount, filled in amber to the proportion that is yours. A 50/50 split fills half. A 60/40 fills 60%. You read the split without reading the numbers.

It is the one invented notation in the system, and it earns its place by encoding real data rather than decorating. It scales: 64px under a list row, full-width under a hero, and segmented per person in the split editor.

Iconography

Material Symbols Rounded, drawn as strokes

Geometry follows Material Symbols Rounded — the set life-os-mobile already uses through Flutter's Icons.*, with outlined objects and rounded chrome.

Drawn on a 24px grid with a 2px stroke, round caps and joins, and currentColor throughout, so one set serves every size and colour. Filled variants exist only where a solid mark is required: the active nav item and category circles.

What the composition proves

The hero carries the month in bg.hero with a full-width share rule showing how much of the cash that left the accounts was actually the user's own.

Amber appears exactly four times — the coin in the mark, the owed nudge, the shared budget bar, and the add button. Each one means the same thing.

The account balances, the activity amounts and the budget figures all sit on the same tabular baseline, so the columns line up down the screen.

Toggle the theme, top right — every surface, border and semantic colour flips from one token set.

Rules that follow

Colour is never the only signal: balance direction always carries a label, budget status always carries a value, and transaction direction always carries a sign. Minimum touch target is 44px. All motion degrades to a cross-fade under prefers-reduced-motion.
